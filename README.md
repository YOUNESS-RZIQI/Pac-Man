# Pac-Man
Recreate the famous arcade game Pac-Man with a modern Python codebase, a clean project structure, and a deployable build.

In this Project i will build a Pac a game using Python and the MLX library for graphics. The game will feature multiple levels, a highscore system, and a cheat mode for testing purposes. The maze generation will be handled by the external `A-Maze-ing` package, ensuring that the game adheres to the original Pac-Man design while allowing for modern enhancements.
